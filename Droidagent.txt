# 🤖 DROID-AGENT — Autonomous Android AI Agent
### Complete Build Specification for Google Jules
**Package:** `com.mahavtaar.droidagent`
**Version Target:** 1.0.0
**Min SDK:** 28 (Android 9) | **Target SDK:** 35 (Android 15)
**Language:** Kotlin + Jetpack Compose
**Architecture:** MVVM + Clean Architecture + ReAct Agent Loop

---

## 📌 PROJECT OVERVIEW

Build a fully autonomous Android Agent app called **DroidAgent** that:

- Runs **on-device LLMs** (Gemma 4 E2B/E4B via LiteRT-LM) with **zero cloud dependency** for core reasoning
- Controls the Android device autonomously via **AccessibilityService** (tap, scroll, type, swipe, launch apps, read screen content)
- Uses a **ReAct (Reasoning + Acting) loop** where the model thinks → decides → acts → observes → repeats
- Has a **modular Skill system** (identical in spirit to Google AI Edge Gallery's Agent Skills) — skills are JSON/Markdown packages that give the agent new capabilities
- **Learns and adapts** over time using an on-device **experience memory** (RAG with SQLite vector store)
- Supports **dual-mode inference**: on-device (LiteRT-LM / Ollama local) + optional cloud fallback (Gemini API)
- Has a **dark, futuristic UI** inspired by Linear and sci-fi terminal aesthetics

This is the most capable open-source autonomous Android agent ever built. No limits.

## 🧠 CORE AGENT ARCHITECTURE

### 1. ReAct Agent Loop — `AgentOrchestrator.kt`

```kotlin
/**
 * The core ReAct (Reason + Act) agent loop.
 *
 * FLOW:
 *   User Goal
 *      ↓
 *   [THINK] LLM generates thought + action JSON
 *      ↓
 *   [ACT] ToolExecutor runs the action on device
 *      ↓
 *   [OBSERVE] Result is fed back to LLM as observation
 *      ↓
 *   [REPEAT] Until goal is achieved or max steps reached
 *
 * Each step is:
 *   1. Build context: system prompt + memories + conversation + available tools
 *   2. Stream LLM output
 *   3. Parse  and  XML blocks from output
 *   4. Execute action via ToolExecutor
 *   5. Append  to context
 *   6. Log step to ExperienceLogger
 *   7. Check if  block found → stop
 */
@HiltViewModel
class AgentOrchestrator @Inject constructor(
    private val llmEngine: LLMEngine,
    private val toolExecutor: ToolExecutor,
    private val memoryRetriever: MemoryRetriever,
    private val experienceLogger: ExperienceLogger,
    private val skillManager: SkillManager,
    private val agentPlanner: AgentPlanner
) {
    // Emit steps as StateFlow for UI observation
    private val _agentState = MutableStateFlow(AgentState.Idle)
    val agentState: StateFlow = _agentState.asStateFlow()

    private val _steps = MutableStateFlow<List>(emptyList())
    val steps: StateFlow<List> = _steps.asStateFlow()

    suspend fun executeGoal(goal: String, maxSteps: Int = 20) {
        val sessionId = UUID.randomUUID().toString()
        val conversation = mutableListOf()

        // Retrieve relevant memories
        val memories = memoryRetriever.retrieve(goal, topK = 5)

        // Build system prompt with tools + skills + memories
        val systemPrompt = buildSystemPrompt(memories)

        // Plan complex goals into subtasks
        val plan = agentPlanner.plan(goal)

        conversation.add(Message.User(buildGoalMessage(goal, plan)))

        var stepCount = 0
        var isComplete = false

        _agentState.emit(AgentState.Thinking)

        while (!isComplete && stepCount < maxSteps) {
            stepCount++

            // Stream LLM response
            val rawOutput = StringBuilder()
            llmEngine.stream(
                systemPrompt = systemPrompt,
                messages = conversation
            ).collect { token -> rawOutput.append(token) }

            val output = rawOutput.toString()

            // Parse thought, action, final_answer
            val thought = extractBlock(output, "thought")
            val actionJson = extractBlock(output, "action")
            val finalAnswer = extractBlock(output, "final_answer")

            if (finalAnswer != null) {
                _agentState.emit(AgentState.Done(finalAnswer))
                experienceLogger.logSuccess(sessionId, goal, steps.value)
                isComplete = true
                break
            }

            // Emit thinking step
            val step = AgentStep.Thinking(thought ?: "Processing...")
            addStep(step)
            _agentState.emit(AgentState.Thinking)

            // Execute action
            if (actionJson != null) {
                _agentState.emit(AgentState.Acting)
                val toolResult = toolExecutor.execute(actionJson)
                val observation = toolResult.toObservation()

                // Add to conversation
                conversation.add(Message.Assistant(output))
                conversation.add(Message.User("\n$observation\n"))

                addStep(AgentStep.Action(actionJson, observation, toolResult.success))

                // Log experience for learning
                experienceLogger.logStep(sessionId, thought, actionJson, observation)
            } else {
                // No action parsed — LLM is confused, nudge it
                conversation.add(Message.Assistant(output))
                conversation.add(Message.User("Please provide a valid  JSON block."))
            }
        }

        if (!isComplete) {
            _agentState.emit(AgentState.Error("Max steps reached without completing goal."))
        }
    }

    private fun buildSystemPrompt(memories: List): String { /* see below */ }
}
```

### 2. System Prompt Template — `res/raw/system_prompt.txt`

```
You are DroidAgent, an autonomous AI agent running entirely on an Android device.
Your purpose is to help the user accomplish any task on their phone or with information.

## YOUR CAPABILITIES
You have access to a set of tools that let you:
- Control the device screen (tap, scroll, swipe, type text)
- Read what is currently visible on screen
- Launch apps, take screenshots
- Search the web, read files, send messages
- Set reminders, check calendar, access contacts
- And more via loadable Skills

## REASONING FORMAT
Always respond in this exact format:

<thought>
[Your step-by-step reasoning about what to do next]
</thought>

<action>
{
  "tool": "tool_name",
  "params": {
    "param1": "value1"
  }
}
</action>

When the task is complete, respond with:

<final_answer>
[Your summary of what was accomplished]
</final_answer>

## AVAILABLE TOOLS
{{TOOL_SCHEMAS}}

## ACTIVE SKILLS
{{ACTIVE_SKILLS}}

## RELEVANT MEMORIES FROM PAST EXPERIENCE
{{MEMORIES}}

## RULES
1. Always think before acting
2. Read the screen after every UI action to observe the result
3. If an action fails, try a different approach
4. Ask for clarification ONLY if absolutely necessary
5. Prefer on-device actions. Use web search only when local data is insufficient
6. Never perform destructive actions (delete, format, uninstall) without explicit user confirmation
7. Be efficient — combine steps where possible
```

### LiteRT Engine — `LiteRTEngine.kt`

```kotlin
/**
 * Uses Google's LiteRT-LM SDK for fully offline Gemma 4 inference.
 * Models: gemma-4-e2b-it-litert-preview (2B), gemma-4-e4b-it-litert-preview (4B)
 *
 * Supports:
 * - Streaming token generation
 * - GPU/NPU acceleration where available
 * - Function calling format compatible with Gemma 4
 * - < 1.5 GB RAM with 4-bit quantization
 */
@Singleton
class LiteRTEngine @Inject constructor(
    private val context: Context,
    private val prefs: AgentPreferences
) : LLMEngine {

    private var session: LlmInference? = null

    override val name = "LiteRT-LM (On-Device)"
    override val isAvailable get() = session != null
    override val maxContextTokens = 8192

    suspend fun loadModel(modelPath: String) = withContext(Dispatchers.IO) {
        val options = LlmInference.LlmInferenceOptions.builder()
            .setModelPath(modelPath)
            .setMaxTokens(maxContextTokens)
            .setTopK(40)
            .setTemperature(0.7f)
            .setRandomSeed(42)
            .build()
        session = LlmInference.createFromOptions(context, options)
    }

    override fun stream(
        systemPrompt: String,
        messages: List,
        temperature: Float,
        topK: Int,
        topP: Float
    ): Flow = callbackFlow {
        val prompt = buildGemmaPrompt(systemPrompt, messages)
        session?.generateResponseAsync(prompt) { partialResult, done ->
            trySend(partialResult ?: "")
            if (done) close()
        } ?: close(Exception("Model not loaded"))
        awaitClose()
    }

    private fun buildGemmaPrompt(system: String, messages: List): String {
        // Gemma 4 instruction format:
        // user\n{system}\n\n{user_message}\n
        // model\n
        val sb = StringBuilder()
        sb.append("user\n")
        sb.append(system)
        sb.append("\n\n")
        messages.forEachIndexed { i, msg ->
            when (msg) {
                is Message.User -> {
                    if (i > 0) sb.append("user\n")
                    sb.append(msg.content)
                    sb.append("\nmodel\n")
                }
                is Message.Assistant -> {
                    sb.append(msg.content)
                    sb.append("\n")
                }
            }
        }
        return sb.toString()
    }
}
```

### Ollama Engine — `OllamaEngine.kt`

```kotlin
/**
 * Connects to local Ollama server (default: http://192.168.x.x:11434)
 * Supports any model available on the local server: llama3.2, mistral, phi4, etc.
 * Uses Ollama's /api/chat streaming endpoint.
 */
@Singleton
class OllamaEngine @Inject constructor(
    private val httpClient: HttpClient,
    private val prefs: AgentPreferences
) : LLMEngine {
    override val name = "Ollama (Local Network)"
    private val baseUrl get() = prefs.ollamaUrl

    override fun stream(
        systemPrompt: String,
        messages: List,
        temperature: Float,
        topK: Int,
        topP: Float
    ): Flow = flow {
        val response = httpClient.post("$baseUrl/api/chat") {
            contentType(ContentType.Application.Json)
            setBody(OllamaChatRequest(
                model = prefs.ollamaModel,
                messages = buildOllamaMessages(systemPrompt, messages),
                stream = true,
                options = OllamaOptions(temperature = temperature, top_k = topK, top_p = topP)
            ))
        }
        response.bodyAsChannel().let { channel ->
            while (!channel.isClosedForRead) {
                val line = channel.readUTF8Line() ?: break
                val chunk = Json.decodeFromString(line)
                emit(chunk.message.content)
                if (chunk.done) break
            }
        }
    }
}
```

### Engine Router — `EngineRouter.kt`

```kotlin
/**
 * Automatically selects the best available inference engine.
 *
 * Priority:
 * 1. LiteRT-LM (on-device, offline, fastest for small tasks)
 * 2. Ollama (local network, larger models, more capable)
 * 3. Gemini API (cloud fallback, maximum capability, requires internet)
 *
 * Falls back automatically if primary engine fails.
 */
@Singleton
class EngineRouter @Inject constructor(
    private val litert: LiteRTEngine,
    private val ollama: OllamaEngine,
    private val gemini: GeminiEngine,
    private val prefs: AgentPreferences
) : LLMEngine {

    private val preferred get() = when (prefs.preferredEngine) {
        "litert" -> litert
        "ollama" -> ollama
        "gemini" -> gemini
        else -> selectBest()
    }

    private fun selectBest(): LLMEngine {
        if (litert.isAvailable) return litert
        if (ollama.isAvailable) return ollama
        return gemini
    }

    override fun stream(systemPrompt: String, messages: List, temperature: Float, topK: Int, topP: Float): Flow =
        preferred.stream(systemPrompt, messages, temperature, topK, topP)
}
```

### Skill Executor — `SkillExecutor.kt`

```kotlin
/**
 * Runs JavaScript skills in a hidden WebView sandbox.
 * The WebView has:
 *   - Network access (fetch API)
 *   - JavaScript interface bridge to Android
 *   - CDN library loading (lodash, etc.)
 *   - No DOM rendering (headless)
 */
class SkillExecutor @Inject constructor(
    private val context: Context
) {
    private lateinit var webView: WebView
    private val pendingResults = mutableMapOf>()

    fun initialize() {
        webView = WebView(context).apply {
            settings.javaScriptEnabled = true
            settings.domStorageEnabled = true
            addJavascriptInterface(SkillBridge(), "Android")
        }
    }

    suspend fun execute(script: String, params: String): String {
        val callId = UUID.randomUUID().toString()
        val deferred = CompletableDeferred()
        pendingResults[callId] = deferred

        val js = """
            (async function() {
                try {
                    $script
                    const result = await execute($params);
                    Android.onResult('$callId', JSON.stringify(result));
                } catch(e) {
                    Android.onError('$callId', e.message);
                }
            })();
        """.trimIndent()

        withContext(Dispatchers.Main) {
            webView.evaluateJavascript(js, null)
        }

        return deferred.await()
    }
}
```

### Learning Engine — `LearningEngine.kt`

```kotlin
/**
 * THE LEARNING SYSTEM — This is what makes DroidAgent smarter over time.
 *
 * After each completed task, LearningEngine:
 * 1. Analyzes the action log (what worked, what failed)
 * 2. Extracts reusable "strategies" (e.g., "to send WhatsApp: open app → search contact → tap message → type → send")
 * 3. Saves strategies as structured memories with embeddings
 * 4. Updates "failure patterns" to avoid repeating mistakes
 * 5. Scores itself (self-evaluation) based on:
 *    - Steps taken vs minimum possible
 *    - Number of retries needed
 *    - User feedback (thumbs up/down)
 * 6. Adjusts strategy weights for future retrieval ranking
 *
 * This creates a SELF-IMPROVING agent that learns device-specific patterns.
 */
@Singleton
class LearningEngine @Inject constructor(
    private val llmEngine: LLMEngine,
    private val memoryStore: MemoryStore,
    private val embeddingEngine: EmbeddingEngine
) {
    suspend fun learnFromSession(session: AgentSession) {
        // 1. Summarize what was done
        val summary = summarizeSession(session)

        // 2. Extract learnable patterns
        val patterns = extractPatterns(session.steps)

        // 3. Self-evaluate
        val score = evaluateSession(session)

        // 4. Store as memories with embeddings
        patterns.forEach { pattern ->
            val embedding = embeddingEngine.embed(pattern.description)
            memoryStore.save(Memory(
                content = pattern.toPromptString(),
                embedding = embedding,
                tags = listOf(pattern.type, session.goal_category),
                outcomeSuccess = score > 0.5f
            ))
        }

        // 5. Update failure blacklist
        session.failedActions.forEach { action ->
            memoryStore.saveFailurePattern(action)
        }
    }

    private suspend fun extractPatterns(steps: List): List {
        val stepsJson = steps.joinToString("\n") { it.toJson() }
        val prompt = """
            Analyze these agent steps and extract reusable patterns.
            Return JSON array of patterns with: type, description, trigger_condition, action_sequence.
            
            Steps:
            $stepsJson
        """.trimIndent()

        val result = llmEngine.generate("You are an AI learning system.", listOf(Message.User(prompt)))
        return parsePatterns(result)
    }
}
```

### Embedding Engine — `EmbeddingEngine.kt`

```kotlin
/**
 * On-device text embedding using MediaPipe Universal Sentence Encoder or MiniLM.
 * Produces 384-dim or 512-dim dense vectors for semantic similarity.
 */
@Singleton
class EmbeddingEngine @Inject constructor(private val context: Context) {
    private var textEmbedder: TextEmbedder? = null

    fun initialize() {
        val options = TextEmbedder.TextEmbedderOptions.builder()
            .setBaseOptions(BaseOptions.builder()
                .setModelAssetPath("universal_sentence_encoder.tflite")
                .build())
            .build()
        textEmbedder = TextEmbedder.createFromOptions(context, options)
    }

    fun embed(text: String): FloatArray =
        textEmbedder!!.embed(text).embeddings.first().floatEmbedding()!!

    fun cosineSimilarity(a: FloatArray, b: FloatArray): Float {
        val dot = a.zip(b).sumOf { (x, y) -> (x * y).toDouble() }
        val normA = sqrt(a.sumOf { (it * it).toDouble() })
        val normB = sqrt(b.sumOf { (it * it).toDouble() })
        return (dot / (normA * normB)).toFloat()
    }
}
```

## 🔄 AGENT FOREGROUND SERVICE

```kotlin
/**
 * Keeps agent alive while executing multi-step tasks.
 * Shows persistent notification with:
 *   - Current task description
 *   - Step progress (Step 3 of 8)
 *   - Current action (e.g., "Opening YouTube...")
 *   - [Pause] [Stop] actions in notification
 *
 * Runs in its own coroutine scope on Dispatchers.Default.
 */
@AndroidEntryPoint
class AgentForegroundService : Service() {
    @Inject lateinit var agentOrchestrator: AgentOrchestrator

    override fun onStartCommand(intent: Intent?, flags: Int, startId: Int): Int {
        val goal = intent?.getStringExtra("goal") ?: return START_NOT_STICKY
        showNotification("Starting...", goal)

        serviceScope.launch {
            agentOrchestrator.agentState.collect { state ->
                updateNotification(state)
            }
        }

        serviceScope.launch {
            agentOrchestrator.executeGoal(goal)
        }
```

## 🔑 KEY IMPLEMENTATION NOTES FOR JULES

1. **LiteRT-LM dependency**: Use `com.google.ai.edge.litert:litert-lm:0.1.0-beta` — check Maven Central for latest. May need to add Google's Maven repo.

2. **Accessibility Service**: The service must be declared in manifest AND the user must manually enable it in Android Settings → Accessibility. Show a deep-link button to the settings page.

3. **Gesture execution**: All `AccessibilityService.dispatchGesture()` calls must happen on the main thread. Use `Handler(Looper.getMainLooper())` for reliable gesture dispatch.

4. **Context window management**: At 8192 token limit, trim old conversation turns keeping: system prompt (fixed) + last 3 user/assistant pairs + latest observation.

5. **Screen reading strategy**: Prefer `UITreeParser` (structured, reliable) over OCR. Fall back to `ScreenCaptureTool` OCR when app doesn't expose accessibility nodes (games, some e-commerce apps).

6. **Model storage path**: Store `.task` model files in `context.getExternalFilesDir("models")` to avoid APK size limits and allow large file storage.

7. **Coroutine scopes**: Agent runs on `Dispatchers.Default`. UI updates collect on `Dispatchers.Main`. Gestures dispatch on main thread via Handler.

8. **Tool output limit**: Truncate tool results to 2000 characters before feeding back to LLM to prevent context overflow.

9. **ReAct output parsing**: Use regex to extract `<thought>...</thought>` and `<action>...</action>` blocks. Handle cases where LLM outputs markdown code fences around JSON.

10. **Safety rails**: Before executing ANY file deletion, app uninstall, or SMS/call action, show a confirmation dialog to user via overlay.
